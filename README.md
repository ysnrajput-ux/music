# YSN MUSIC

Modern music streaming web app inspired by Spotify.

## Features

- Song search
- Audio streaming
- Trending songs
- Mini player
- PWA support
- Mobile responsive
- Lock screen controls

## Tech Stack

### Frontend
- HTML
- TailwindCSS
- JavaScript

### Backend
- Node.js
- Express
- yt-search
- ytdl-core
